Для разбиения я предполагаю использовать Module Federation, что позволит использовать разные библиотеки без проблем.
Например, когда потребуется доработать или обновить систему авторизации. Добавить возможность регистрации через стороние сервисы такие Google или Apple.
Или, например, добавить функционал добавления видео или их просмотр в том же окне, что и фото, а для лайков и комментариев использовать тот же функционал.
Помимо этого, данное решение позволит не подгружать видео целиком, при загрузке главной страницы профиля.

Проект будет состоять из 4-х модулей:
- Авторизация/регистрация (auth-microfrontend) - в него будут вынесены модули, отвечающие за регистрацию и авторизацию. Данные элементы объединены в один так как напрямую зависят друг от друга.
При авторизации пользователь может вводить данные, которые может не быть в системе и следовательно может потребоваться регистрация, и наоборот.
Соответственно этот модуль включает себя: Login и Register, а также InfoTooltip для уведомлений о регистрации
- Взаимодействие с профилем (profile-microfrontend) - в него вынесен функционал отвечающий за редактирование и работу с уже имеющимся профилем.
Включает в себя такие компоненты как: EditAvatarPopup и EditProfilePopup.
- Взаимодействие с фото (image-microfrontend) - в него вынесен функционал, отвечающий за загрузку фотографий и их просмотр, но не открытие их с главной страницы профиля, отображение самих фотографий при открытии.
Включает в себя такие компоненты как: AddPlacePopup и ImagePopup.
- Главная страница (card-microfronted) - в него вынесен функционал по работе с главной страницей профиля, который уже в дальнейшем использует функционал других микросервисов
Включает в себя такие компоненты как: Card, Main, Footer.

Порядок запуска.
При открытии страницы первым запускается модуль Главной страницы, который в дальнейшем позволяет запускать другие модули в зависимости от действий пользователя.
При авторизации/регистрации - модуль Авторизации/регистрации.
При редактировании профиля соответственно модуль Взаимодействия с профилем.
При добавлении или просмотре фото - модуль Взаимодействия с фото.
